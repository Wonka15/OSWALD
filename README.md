# OSWALD 2.0 — Creative Companion

A personal, local-first AI assistant project for Windows 11, with planned cross-platform workflows for macOS and Raspberry Pi.

## Project status

**Early access / experimental.** This repository is being prepared for the OSWALD 2.0 source release. Do not assume this repository currently contains the complete application until the source files are uploaded and verified.

## Intended capabilities

- Local AI backends: Qwen and Gemma through Ollama; Nemotron through a local llama.cpp server
- Godot 4 starter-project generation and beginner lessons
- Processing creative-coding templates and lessons
- Macintosh SE / System 6 reference assistance
- Raspberry Pi diagnostics, offline voice options, local knowledge and memory
- SVG design concepts and static application-inspection workflows

## Hardware target

Windows 11, AMD Ryzen, 16 GB system RAM, Radeon Vega 56 (8 GB VRAM). Real GPU inference and VRAM benchmarks are **not yet validated** on the target machine.

## Security

Run locally, under a non-administrator account. Do not expose development services to the public internet. Do not store secrets or personal knowledge databases in Git.
